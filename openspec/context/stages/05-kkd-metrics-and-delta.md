## Результат этапа

Прикладная сводка отдаёт три метрики, severity и new/persisting/resolved по snapshot-данным; все граничные unit-тесты проходят без HTTP.

## Входит в этап

- Реализовать чистые расчёты трёх метрик, разбивки по важности и дельты проблем.
- Добавить чтение двух снимков и сборку прикладной сводки по подразделению.
- Проверить округление, отсутствие истории, перенос целей и неизменность старых результатов.

## Не входит

- Контроллеры, JSON DTO и HTTP-ошибки.
- Кеш, материализованные представления, новые таблицы метрик и SQL-аналитика.
- Изменение трёх согласованных метрик.
