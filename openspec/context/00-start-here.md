# 00 — Start Here

## KKD Service

Java backend-сервис для контроля качества данных по целям и ключевым результатам.
Сервис проверяет данные PostgreSQL, сохраняет результаты проверок и предоставляет REST API
для визуализации метрик и динамики качества данных.

## Главные запреты

- ❌ **Не создавайте бизнес-сущности и REST API до согласования контекста.**
- ❌ **Validation Engine не зависит от Spring, JPA и базы данных.**
- ❌ **Контроллеры не обращаются к репозиториям напрямую.**
- ❌ **Не используйте JPA Entity напрямую как DTO в API.**
- ❌ **Не логируйте чувствительные данные (ФИО, owner_id, токены, полные тела запросов).**
- ❌ **Не добавляйте зависимости без согласования.**
- ❌ **Не создавайте аутентификацию/авторизацию в v1.**

## Статус проекта

Проект на начальной стадии — только Spring Boot skeleton.
Все бизнес-сущности, миграции, контроллеры и сервисы должны быть созданы.
