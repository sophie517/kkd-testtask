# Spec Delta

## Purpose

Сейчас есть skeleton, но отсутствуют Docker Compose и подключённый changelog. Нужна воспроизводимая основа, на которой следующий этап сможет создать доменную схему.

## ADDED Requirements

### Requirement: Запуск инфраструктуры одной командой

Система SHALL запускать Java-приложение и PostgreSQL одной командой docker compose up с согласованными параметрами подключения.

#### Scenario: Первый запуск демо
- **WHEN** репозиторий получен без .env и контейнеры запускаются на чистом volume
- **THEN** приложение подключается к PostgreSQL с локальными демонстрационными настройками

#### Scenario: Переопределение реквизитов
- **WHEN** пользователь задаёт имя пользователя и пароль через окружение Compose
- **THEN** БД и приложение получают одинаковые реквизиты и соединение устанавливается

### Requirement: Готовность PostgreSQL

Приложение SHALL запускаться после подтверждения готовности PostgreSQL.

#### Scenario: Ожидание базы
- **WHEN** PostgreSQL ещё не завершил инициализацию
- **THEN** приложение ожидает успешный healthcheck БД

### Requirement: Автоматическое применение changelog

Система SHALL читать Liquibase changelog при старте и не создавать доменную схему средствами Hibernate.

#### Scenario: Инфраструктура без доменных изменений
- **WHEN** приложение запускается с пустым корневым changelog
- **THEN** запуск успешен, доменные таблицы отсутствуют

#### Scenario: Повторный старт
- **WHEN** инфраструктура запускается повторно с тем же volume
- **THEN** подключение успешно и существующие данные сохраняются
